# Student Task Manager

A simple Java Swing based desktop application designed to help students manage their daily academic tasks in an organized way.

## 📌 About the Project

The Student Task Manager allows students to add, view, complete, and delete their tasks through a simple graphical user interface.

The application also includes a student login and registration system.

## ✨ Features

- 🔐 Student Login
- 📝 Student Registration
- ➕ Add New Tasks
- 📋 View All Tasks
- ✅ Mark Tasks as Completed
- 🗑️ Delete Tasks
- 📌 View Completed Tasks
- 🖥️ User-friendly graphical interface
- 📅 Add task deadlines
- 📝 Add task descriptions

## 🚀 How to Run the Project

Method 1: Using IntelliJ IDEA

Download or clone this repository.

Open the project in IntelliJ IDEA.

Make sure a suitable JDK is configured.

Open the src folder.

Open LoginPage.java.

Right-click on LoginPage.java.

Select Run 'LoginPage.main()'.

The Student Task Manager login page will open.

Using the Application

Click REGISTER to create a student account.

Enter your desired username and password.

After successful registration, enter the same credentials on the login page.

Click LOGIN.

The Student Task Manager dashboard will open.

Use ADD TASK to create a new task.

Use MY TASKS to view your tasks.

Mark tasks as completed when finished.

Use COMPLETED TASKS to view completed tasks.

Use DELETE TASK to remove a task.
